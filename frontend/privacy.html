Privacy

CommitCraft publishes files from your computer to GitHub repositories you choose. This page describes exactly what is handled.

What stays in your browser

Your selected folder, commit plan and preferences like theme are kept in your browser (IndexedDB and localStorage) so you can resume a publish. Clear them anytime in Settings. GitHub tokens are never stored in the browser.

What our server stores

  • Your GitHub user id, login and avatar URL for the session.
  • Your GitHub access token, encrypted with AES-GCM, for up to 7 days or until you sign out.
  • Publish jobs: repository, branch, file paths, commit messages and resulting commit SHAs (30 days), and a history summary (90 days).
  • Your settings.

What we do not store

File contents are sent to GitHub to create Git blobs and are not stored by CommitCraft.

Your controls

Sign out to end the session, use Disconnect GitHub to revoke CommitCraft's access, and clear history from Settings.
